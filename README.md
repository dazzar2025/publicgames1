# 🔢 Merge 2048

Slide the tiles and merge matching numbers to reach 2048.

**▶ Play now:** https://dazzar2025.github.io/publicgames1/

- Works on phones, tablets and desktop browsers — no install, no sign-up
- Controls: swipe on the board, or arrow keys / WASD. One-step undo.
- Your best score is saved in your browser

Single self-contained `index.html` — no build step, no dependencies.
